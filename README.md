# 面试地图 · Internship Atlas

**为自己的实习面试准备而做：从岗位和问题出发，沿概念关系和追问链复习。**

[在线使用](https://ace-teng.github.io/find_job_cs/) · [补充问题 / 纠错](https://github.com/Ace-teng/find_job_cs/issues)

10 个岗位入口 · 78 个问题 · 470 个概念 · 525 条关系。数字以 `data.json` 为准。

## 怎么用

1. 选择前端、Java / Go / Python 后端、全栈、AI / Agent、机器学习、测试、运维或 C++ 岗位。
2. 搜索问题或概念；按模块和准备顺序筛选。
3. 打开问题，浏览追问链或切换关系图；点击概念继续跳转。
4. 标记待复习、不熟、已掌握，收藏薄弱问题。
5. 需要组织回答时再展开简短提示。默认只展示概念关系。

进度只保存在当前浏览器，不上传。换设备或清理缓存前请导出 JSON，在另一个设备导入。手机支持完整筛选和关系列表。

## 内容边界与时效

没有独立的数学或理论课程目录；基础知识跟随岗位问题出现。准备顺序是编辑建议，**不是统计得到的面试频率**。问题与追问链不是某家公司的真实题库。

`追问` 表示建议的复习顺序；`依赖`、`使用`、`对比` 等表示具体技术关系。不要把追问箭头理解成技术因果。内容整理日期为 2026-10-12；React、LangChain、LangGraph、RAG 与 MCP 的标记来源已在该日核对，其余链接是参考入口，不声称逐条核验。AI 生态变化较快，页面展示核验日期，使用时可继续查看官方文档。

## 本地预览

无需安装依赖：

```sh
python3 -m http.server 8080
```

打开 `http://localhost:8080`。不要直接双击 HTML（浏览器会限制读取 JSON）。

```sh
node --check app.js
node scripts/validate.mjs
```

## GitHub Pages

Settings → Pages → Deploy from a branch → `main` / `/ (root)`。`.nojekyll` 关闭 Jekyll；所有资源使用相对路径，支持仓库子路径。每次推送自动更新网页；Actions 检查 JavaScript 和知识数据引用。

## 贡献

`data.json` 是运行时内容，`scripts/seed.py` 是当前初始内容的可编辑来源。修改初始内容时运行 `python3 scripts/seed.py`，再运行校验。新增问题应包含岗位、模块、概念链、简短回答提示与来源；技术关系与追问关系必须区分。现有 ID 对应用户进度，**不要改变或重排已有 ID**；新增节点与问题应在末尾追加。生成器会保留已有名称和题目的 ID；重命名需要显式迁移。生成器会重建数据，直接修改 JSON 的内容请同步到生成器，防止丢失。

提交 Issue 时可以提供真实面试问题（去掉个人和公司敏感信息）、官方来源或错误关系。贡献概念比罗列工具名称更有价值。
