# 面试地图 · Internship Atlas

**为自己的实习面试准备而做：从岗位和问题出发，沿概念关系和追问链复习。**

[在线使用](https://ace-teng.github.io/find_job_cs/) · [补充问题 / 纠错](https://github.com/Ace-teng/find_job_cs/issues)

10 个岗位入口 · **90 道具体练习 + 78 个概念总览** · 700 个概念 · 862 条关系。数字以 `data.json` 为准。

## 怎么用

1. 选择前端、Java / Go / Python 后端、全栈、AI / Agent、机器学习、测试、运维或 C++ 岗位。
2. 默认进入具体练习；按模块、来源、公司、题型和准备顺序筛选。
3. 打开问题，浏览追问链或切换关系图；点击概念继续跳转。
4. 标记待复习、不熟、已掌握，收藏薄弱问题。
5. 先看面试场景与后续追问，需要时再展开回答要点和易错点。默认不展开答案。

进度只保存在当前浏览器，不上传。换设备或清理缓存前请导出 JSON，在另一个设备导入。手机支持完整筛选和关系列表。

## 内容边界与时效

没有独立的数学或理论课程目录；基础知识跟随岗位问题出现。准备顺序是编辑建议，**不是面试频率统计**。

- **面经改编**：主题来自有链接的公开作者自述，题目经改写，场景与追问为编辑扩展；不冒充公司官方真题。
- **文档练习**：根据官方文档的技术语义编写，不附虚构公司标签。
- **概念总览**：首版 78 个宽口径入口，保留原 ID 和复习进度，在来源筛选中单独浏览。

本次近期面经范围为 **2024-10-12 至 2026-10-12**，纳入记录均来自 2025 / 2026。面试日期与帖子日期分开标注；不能确认年份的帖子未纳入。原帖没有明确实习招聘的记录，也在详情里说明招聘范围。

本次具体练习共使用 7 篇公开面经及 66 个技术文档 / 官方题目入口；每题显示链接和核验时间。官方文档主要支持技术语义，题目出处支持练习要求；回答要点由编辑整理，来源不是逐字答案。源码中的 `verified` 表示本次查看页面时间，不代表官方文档发布日期。版本敏感题明确说明 Go 1.22 循环变量、Python 自由线程构建和协议版本前提。

`追问` 表示建议的复习顺序；其他连线标明技术关系。不要把追问箭头当作技术因果。近期来源索引见 [SOURCES.md](SOURCES.md)。

## GitHub Pages

Settings → Pages → Deploy from a branch → `main` / `/ (root)`。`.nojekyll` 关闭 Jekyll；所有资源使用相对路径，支持仓库子路径。每次推送自动更新网页；Actions 检查 JavaScript 和知识数据引用。

## 贡献

`data.json` 是运行时生成内容。`scripts/seed.py` 保留首版总览；`content/drills.json` 保存具体练习、版本前提与来源；`scripts/enrich.py` 合并两者。编辑后运行 `python3 scripts/seed.py`，再运行校验。新增问题应包含岗位、模块、概念链、简短回答提示与来源；技术关系与追问关系必须区分。现有 ID 对应用户进度，**不要改变或重排已有 ID**；新增节点与问题应在末尾追加。具体练习使用稳定的 `drill-*` ID；新概念 ID 根据名称生成。总览 ID 沿用首版。重命名需要显式迁移。不要直接修改生成的 `data.json`，防止下次生成丢失。

提交 Issue 时可以提供真实面试问题（去掉个人和公司敏感信息）、官方来源或错误关系。贡献概念比罗列工具名称更有价值。
